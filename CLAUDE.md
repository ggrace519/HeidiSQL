# HeidiSQL AI Edition — working notes for Claude

Fork of the HeidiSQL Lazarus/FreePascal port that adds an AI SQL assistant. Read
`AI-EDITION.md` (what differs from stock) and `DECISIONS.md` (why) first.

## Build and run
- Toolchain: Lazarus 4.8, FPC 3.2.2 (same as CI). `lazbuild` is at `/usr/bin/lazbuild`.
- Build: `make build-gtk2` (about 5 s, output `out/gtk2/heidisql`). Also `build-qt5`, `build-qt6`.
- Run: `./out/gtk2/heidisql`. Settings go to `~/.config/heidisql-ai/`, never to the stock
  `~/.config/heidisql/`. Use `XDG_CONFIG_HOME=<dir>` to run against a throwaway settings folder.
- Translations in a local build: `make copy-locale` copies the .mo files to `out/locale/`, but the
  app looks next to the executable, so also run `ln -sfn ../locale out/gtk2/locale`. Then
  `LANG=de_DE.UTF-8 LANGUAGE=de ./out/gtk2/heidisql` starts in German.
- No tests yet. A fpcunit test project with `make test` arrives with the first AI core units.

## Branches
- `lazarus` = released branch, where upstream is merged in. `develop` = integration branch.
- Feature branches `<type>/<kebab-summary>` from `develop`. PRs target `develop`; promotion
  `develop` → `lazarus` is a merge commit PR, never squash.

## Code rules
- New logic goes into new, small, single-purpose units. `main.pas` (16k lines), `apphelpers.pas`
  and `dbconnection.pas` only get short hooks, marked with an "AI Edition:" comment.
- Do not edit upstream `.lfm` files (`main.lfm`, `preferences.lfm`, `connections.lfm`). Create
  new UI at runtime, or as new frames with their own `.lfm`.
- LCL-free units (`forkpaths`, `forkupdate`, future `ai.*` core units) must not use LCL,
  `apphelpers` or `dbconnection`, so the test project can compile them.
- Strings shown to users go through `_()` / `f_()` and are added to `extra/locale/heidisql.po`.
- New units are compiled when a `uses` clause reaches them; also add them to the `<Units>` list in
  `heidisql.lpi` for the IDE.
- Constants for the fork (`APPDISPLAYNAME`, `APPCONFIGDIRNAME`, `AIEDITIONVERSION`, release
  URL) are in `source/const.inc`, which `apphelpers` includes in its interface.

## Docs to keep in sync
- `CHANGELOG-AI.md` `[Unreleased]` for every user-visible change. Upstream `CHANGELOG.md` is
  generated by git-cliff; do not edit it.
- `AI-EDITION.md` when behavior that differs from stock changes.
- `DECISIONS.md` for architecture and process decisions.

## Gotchas
- `pgrep -f`/`pkill -f out/gtk2/heidisql` also matches the shell running the command and kills
  it. Use `pgrep -x heidisql` and check `/proc/<pid>/exe`.
- Actions added to `MainForm.ActionList1` after the caption snapshot in `TMainForm.FormCreate`
  (loop filling `FActionList1DefaultCaptions`) break Preferences > Shortcuts.
- `TDBConnection` is not thread-safe. Read schema data on the main thread.
